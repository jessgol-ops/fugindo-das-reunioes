# Fugindo das Reuniões 🏃‍♀️📅

Jogo 8-bit de corrida infinita no navegador: fuja dos calendários de reunião e dos balões da chefia, e pegue café para recuperar vida.

**Funciona no computador e no celular**, sem instalar nada: é um único arquivo `index.html`.

## Como jogar

| Ação | Computador | Celular |
|---|---|---|
| Pular calendários | `Espaço`, `↑` ou `W` | Botão ▲ ou tocar na tela |
| Abaixar dos balões | `↓` ou `S` (segurar) | Segurar o botão ▼ |
| Pausar | `P` ou `Esc` | Botão ❚❚ |
| Som liga/desliga | `M` | — |

- ☕ Café recupera 1 vida e vale +50 pontos.
- A velocidade aumenta aos poucos, como no jogo do dinossauro do Chrome.
- A cada 100 pontos o placar pisca.
- O recorde fica salvo no navegador.

## Rodar localmente

Abra o `index.html` no navegador. Pronto.

## Publicar no GitHub Pages

Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`. O jogo fica disponível em `https://<seu-usuario>.github.io/fugindo-das-reunioes/`.

## Tecnologia

HTML, CSS e JavaScript puros, com Canvas 2D. Sprites em pixel art e efeitos sonoros 8-bit gerados no próprio código (Web Audio API). Fonte: [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P).
